# 公开仓库与私有题库的边界

Toy 独立版本同样遵守本文件的答案保护规则。`scripts/build_toy.py` 只组装公开文件白名单，复用公开题库；云端按题型及题集版本保存 `v/revision/completed/pending`，另存不含账号信息的随机缓存隔离标记 `wk_scope_v1`。浏览器缓存仅增加模式容器，不保存输入、答案、解题过程或身份凭据。不调用用户资料 API，本地待重试数据必须与当前云标记匹配才合并；同步只使用白名单进度。普通网站存档码不会打入 Toy 包，Toy 也不读取普通网站的本地存档。截图测试仅使用人工数据并输出到仓库外。云同步的覆盖式 KV 并发限制见 [Toy 版本计划](toy-plan.md)。

公开仓库保留生成器代码、规则定义、通用 HSK／CC-CEDICT 词库、人工测试夹具，以及不列出具体答案的汇总统计。

以下内容保存于仓库外：完整 SQLite 题库、题面与答案映射、含解答的 JSON／Markdown／HTML 示例、原始数据缓存、截图，以及清理前的 Git 历史备份。通用词库虽然包含可以作为答案的汉字和词语，但不含“某题对应哪个答案”的记录，不属于题目答案表。

## 存储约定

### 网页版无尽模式的运行时边界（2026-10-02）

无尽模式已实现浏览器直接生成，尚未执行线上部署。允许公开通用词库、通用生成算法及独立选定的固定种子；允许在运行时内存中生成标准答案、检查唯一解及维护最近 100 关答案字冷却。真实题目的明文答案映射、完整组词、答案候选下标和可逆编码的冷却检查点不得发布，也不得写入前端存档、持久化缓存或日志。通用种子不得编码预先选定的答案序列。本轮不考虑开发者工具提取或重放；这不构成严格保密承诺。Worker 只返回题面、ID、盐和校验摘要；存档只写版本与下一关号。审计将 `endless-lexicon.json` 与完整通用词库逐项核对，Worker 另行核对固定版本词库的 SHA-256。恢复进度的重算与性能边界见 [无尽模式说明](endless-mode.md)。以下私有文件存储约定继续适用于离线含答案产物。

默认私有目录为仓库旁的 `<仓库名>-private/word-kanji`。本地仓库为 `C:\Code\puzzle` 时，对应 `C:\Code\puzzle-private\word-kanji`。可以通过环境变量 `WORD_KANJI_PRIVATE_DIR` 指定其他仓库外目录。

所有会输出解答的生成命令默认写入私有目录，并拒绝将私有产物写入当前仓库，即使该路径已被 Git 忽略。仍可通过 `--output` 指定其他仓库外路径。

```powershell
$env:WORD_KANJI_PRIVATE_DIR = 'C:\Code\puzzle-private\word-kanji'
python -X utf8 word-kanji/generator.py
python -X utf8 word-kanji/scripts/select_one.py
```

测试使用人工字表或仅存在于内存的运行时生成结果，不在仓库中保存真实题库的解答夹具。词表规范化测试可以保留普通字词，因为它们不对应任何公开题面。

## 提交前检查

```powershell
python -X utf8 -m unittest discover -s word-kanji/tests -v
python -X utf8 word-kanji/scripts/audit_public.py
python -X utf8 word-kanji/scripts/audit_public.py --staged
python -X utf8 word-kanji/scripts/audit_public.py --history
```

检查脚本拒绝已知私有产物路径和答案映射字段，允许词库及数量统计；对自由文本规则说明仍需人工审阅。历史检查覆盖所有可达 Git 引用，避免只删除当前文件却留下旧版本。

私有目录、Git 备份包和生成缓存不应进入静态网站的部署目录。现有包含解答的生成格式只用于私有工作流。

## 静态闯关页面

帮助中的专用教学例题不作为可玩关卡答案表：一字沿用已移出闯关的旧例题，2026-10-02 二字按用户明确指定的教学答案词制作，按钮切换展示。二字例题使用一个正式 HSK 生成范围外的通用组词，且在扩展词库中复核单解；因此当前无尽生成规则不会生成同题。测试从帮助标记读取教学内容，检查现有公开题集及同题位置互换不重合。后续变更例题或扩展生成词库时必须重新核对这条边界，不得直接发布真实关卡的明文解答。

部署范围仅为 `word-kanji/public/` 内的文件，在网站上对应 `/puzzle/word-kanji/`。`word-kanji/scripts/export_campaign.py` 从仓库外的筛选数据库生成 `word-kanji/public/campaign.json`，采用严格字段白名单，并由审计脚本检查其嵌套结构。项目内的本地预览服务也只映射本项目的 `public/`，不将仓库作为资源根目录。

每题仅发布随机 ID、四个题面字、四个线索词的等级、难度、随机盐和校验摘要。摘要输入为 UTF-8 编码的 `kanji-one-v1:<id>:<salt>:<NFC(trim(input))>`，算法为 SHA-256。不同题目独立加盐；内部题目 ID、答案分组、完整词语和答案字均不导出。

这是避免明文答案的静态判题方案；答案空间有限，仍可离线穷举摘要，不能严格保密。通过 Web Crypto 检查玩家输入，前端不加载私有数据库。生产部署需要 HTTPS，本地 localhost 可以测试。

二字生成器 `scripts/generate_two.py` 将最难题面缓存、选题与明文答案保存在仓库外 `datasets/two-standard-hsk-word-guess/`，仅将白名单字段导出到 `public/campaign-two.json`。公开记录包含六个题面字、七条组词关系的 HSK 等级、排序难度整数、随机 ID、盐及摘要；不导出完整组词、内部词条 ID 或答案映射。摘要前缀为独立的 `kanji-two-v1`，输入为依左右顺序拼接的两字。

二字回看会按需加载 `public/hsk-two-words.json`，这是完整通用 HSK 二字词表，包含与题目无关的词汇，既不按关卡排序也不携带题目 ID。审计时逐项核对其与通用源词库完全相同，防止变成题目专属的候选表或关联表。结果仅在内存中处理，不持久化解答；公开摘要可以用该词表穷举，不提供严格保密性。

当前二字筛选在私有内存中读取一字答案映射，按“完整词语＋待猜位置”排除已用线索，所用集合及对应关系不导出。私有缓存绑定一字公开文件哈希和筛选规则版本。旧 406 题公开文件备份在新私有生成目录，前端仅发布当前 311 题。

二字排序使用两种填字顺序的最优瓶颈分数，公开 `difficulty` 为一个整数。已知答案字的方向计数和每一步分数仅在私有计算中使用，不发布答案分项或解题顺序；筛选仍使用原六项外部线索计数。详见[二字难度](two-difficulty.md)。

已通关关卡的「查看答案」按需枚举通用 Unicode 汉字并匹配摘要，结果仅在当前页面运行时显示，导航时清除，不写入存档、历史状态或任何缓存。已通关限制属于界面行为，不构成答案访问的安全边界。

localStorage 仅保存题集版本、实际通过数和已解锁范围内未通过题号（玩家进度，不含填字内容）。原 v1 记录保留，新记录写入独立 v2 键。判题成功后只读显示玩家当前填字，仍属于运行时输入；切换关卡、返回或离开页面时清除，不把玩家填过的正确内容保存为答案缓存。刷新后不恢复输入。相同题集重复导出保留公开标识、校验数据和版本；实际题集变更需明确迁移规则。
