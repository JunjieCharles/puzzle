# 文本存档码

入口位于帮助按钮左侧。导出码可直接发送到另一台设备，再粘贴导入；不需要账号。打开存档弹窗不会暂停自动切关，执行有效导入时恢复对应模式：闯关进入选关页，无尽进入下一道待完成关。复制失败时可手动选择文本复制。

## 当前格式

`HT101-2.<Base64URL JSON>.<16 位十六进制校验码>`，继续接受原 `HT101-1` 存档。

JSON 包含协议版本 `v: 2`、每次导出重新生成的 128 位随机 `nonce`、按模式名称组织的 `modes`。闯关支持 `campaign-one-standard` 和 `campaign-two-standard`，各自记录 `revision`（题集版本）、`completed`（实际已通过题数）和 `pending`（已解锁范围内未通过的题号，1 起算、升序、不重复）。2026-10-02 新增 `endless-one-standard` 和 `endless-two-standard`，只记录 `revision`（当前 `endless-v1`）与 `next`（下一道待完成关，从 1 开始）；无尽不允许跳关，因此没有 `pending` 或通过列表。不含玩家输入、答案、完整组词、设备身份或认证信息。以下解锁窗口规则仅针对闯关。

解锁范围为前 `min(总题数, completed + 3)` 题；范围内除 `pending` 外均已通过，范围外全部未通过。`pending` 最多三个题号，数量必须等于解锁数减去通过数。初始通过数为 0、未通过题号为 `[1,2,3]`（总题数不足三题时截断）；全部通过时为空。不是把所有尚未解锁题号逐个存入码中。

旧协议中缺少 `pending` 的记录按前 `completed` 题全部通过转换，再扩展三个可选题。新版界面始终导出协议 2；底层编码函数为旧记录保留协议 1 的编码能力。旧客户端会拒绝协议 2，避免将乱序通过数误读为连续通关数。

校验码是前两段（含分隔点）的 SHA-256 前 16 位十六进制字符，用于发现复制错误，不是签名或防作弊机制。Base64URL 仅作文本编码，不是加密。随机值用于使相同进度的导出码不同，不代表玩家身份。

## 验证与导入

- 接受复制时产生的空白和换行，限制输入长度为 65,536 字符。
- 校验协议版本、JSON 格式、随机值、摘要、已知模式的记录；进度必须是非负安全整数，当前模式还不得超过当前题集关卡数。
- 当前模式题集版本必须匹配。跨题集仅按关号恢复可能对应不同题目，因此不自动套用；失败时不更改当前存档。
- 明确迁移例外：`cbe3a2f1ecd820a5` 的 587 关题集移除原第 197 关后成为 `3a92ed63edc4ea56` 的 586 关题集。旧进度 0–196 不变，197–587 减一；本地读取及文本码导入均支持。该例外不代表任意题集版本都可互通。
- 合并双方已通过题号的并集，再重新计算通过数与未通过题号；即使两份存档通过数相同、通过题目不同，也不会互相覆盖。成功后立即尝试写入 v2 localStorage 并进入选关页。写入失败时可继续本次游戏，同时提示用户保留文本码。
- 同时读取旧 v1 和新 v2 本地记录，保留原 v1 原文、不覆盖也不删除；旧页面继续向 v1 写入的合法连续进度会在下次读取时合并。任一记录损坏不影响读取另一份有效记录。

## 后续增加模式

模式名称固定且不可换义。二字型使用独立名称 `campaign-two-standard`，继续读取版本 1 的既有一字型字段；缺少的新模式记录表示没有已保存进度，新玩家从零开始，已有本地进度不清除。

增加可选模式不需要提升协议版本，也不能要求旧码包含新模式。当前解析器忽略未知模式，不保存或重新导出它们；不承诺旧客户端完整读取新客户端存档。本次因引入乱序通过状态提升至协议 2，保留协议 1 解析和迁移入口。

导出时写入一字闯关记录及有通过进度的二字闯关、无尽记录；导入时逐个验证本版本支持的模式，并在全部验证通过后合并应用。任何一个已知模式不合法时，所有模式均不应用该码的进度。无尽版本必须匹配，`next` 必须是 1 至 `Number.MAX_SAFE_INTEGER - 1` 的整数；同模式导入取双方较大的关号，不回退进度，旧码缺少无尽记录时保留本地进度。新增可选模式仍使用协议 2；协议 2 的 `pending` 必填约束只针对闯关记录，协议 1 不接受无尽记录。

无尽本地键分别为 `word-kanji:endless-one-standard:v1` 和 `word-kanji:endless-two-standard:v1`，每份只有 `revision/next`。刷新后 Worker 从固定起点重放恢复冷却，不从存档读取答案或冷却状态。浏览器存储不可用时保留本次会话进度并显示导出提示；未知或损坏的无尽本地记录阻止对应模式继续，不影响闯关和另一种无尽题型。写入时可用则使用浏览器锁，无锁环境仍可能有极端同时写入竞争。

本次机制变更不改题库文件或版本：一字仍为 `3a92ed63edc4ea56`，二字仍为 `d50323fe85aaf35b`。原 587 关迁移例外仍仅用于一字旧顺序进度。新 localStorage 分别使用 `word-kanji:campaign:v2` 和 `word-kanji:campaign-two:v2`，同时读取并保留对应 v1 键。原有仅含一字进度的旧码在任一页面均可导入，并进入一字选关页。

保存、页面导航及导入导出时重新读取本地进度并合并已通过题号，不使用跨标签页实时监听。可用时用浏览器写锁串行保存；无写锁时读后合并再写，极端同时写入仍可能竞争。正常过关保存失败也持续显示导出入口，保存成功后隐藏。

### 二字开发期题集

2026-09-11 用户确认发布二字标准型。此前用户明确首发前开发期更换题库不处理迁移，因此不维护这些二字旧版本例外或排序迁移表。二字本地版本不匹配时从零进度开始，含不匹配二字记录的文本码按既有版本校验规则拒绝；原有一字存档兼容性不变。后续更换已发布二字题库须重新评估进度兼容。

本地读取不会立即删除旧记录，后续保存成功时写入当前版本。旧公开二字题库与私有生成数据保留在仓库外备份。
