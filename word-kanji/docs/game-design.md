# 闯关页面设计需求

本文件记录当前有效的产品需求和交互约定。游戏规则见 [规则定义](wadou-kaichin-rules.md)，数据边界见 [公开与私有边界](public-private.md)。后续设计调整必须同步更新本文件。

## 用户明确的需求

- 静态网站，访问路径为 `/puzzle/word-kanji/`，保留最简基本功能。
- 首页选择「闯关模式」或「无尽模式」；无尽模式暂未开放。
- 闯关模式选择「一字标准型」或「二字标准型」；二字标准型暂未开放。
- 点击「一字标准型」先进入选关界面，再进入题目。
- 一字标准型使用已筛选的一千多道题（当前 1,408 道），包含 HSK 7–9 级。
- 总体从易到难排列，相同答案的题目不能离得太近。
- 难度按四个题面字在对应词首或词尾可组成的二字词数量评定，计数采用更大的词库；将四项计数从小到大排序，再按字典序比较，越大越难，不求和。
- 同答案线索词去重筛选也按新难度重新执行，仍先保留较难的题目再排除重复词。
- 填空区自动只保留一个字，即使输入或粘贴了多个字。
- 切换到下一关后可以直接输入，不需要再次点击填空区。
- 页面暂不添加玩法说明、词库来源等解释性文字；保留功能按钮、必要状态反馈和未开放标记。
- 仓库及前端不保存真实题目的明文答案，提交前检查。

## 当前实现默认

以下为满足需求采用的当前实现选择，并非用户逐项指定的规则。

### 选关与进度

- 每页 60 关，支持上一页、下一页及关卡范围选择。
- 已通关关卡可重玩，下一道未完成关卡可进入，其余关卡逐关解锁。
- 选关页标记已通关及当前待完成关卡，并提供「继续闯关」。
- 答题页可返回选关、进入上一关或回到当前闯关进度。
- 关卡地址使用 `#play/<关卡编号>`；刷新指定关卡仍停留在该关，未解锁或无效编号返回选关。
- 全部通关后可重玩；「再玩一次」会从头开始并重置进度。
- 本地仅保存题集版本和已过关数，不保存玩家输入或标准答案。重新导出题集会更新版本，旧版进度从头开始。

### 输入与判题

- 多字输入保留第一个 Unicode 字符，扩展区汉字不被拆成两个字符；中文输入法在选字完成后截取，不打断拼音组合过程。
- 进入或切换关卡后自动聚焦填空区；支持按钮提交和回车提交，输入法组合期间不提交。
- 非单个汉字给出输入反馈，错误答案允许重试，正确答案显示过关并开放下一关。
- 判题采用题目绑定的加盐 SHA-256 摘要；成功后清除输入，不提供明文答案展示或缓存。
- 加载失败可以重试；本地存储不可用时仍可在当前会话内游玩。

### 排序与页面

- 扩展计数词库采用 HSK 全等级与 CC-CEDICT 的二字词并集，按字面去重。上、左题面字统计作词首的数量，下、右统计作词尾的数量；无需再按答案字域或题面互异性排除词条。
- 四项计数升序排列后的字典序作为唯一难度依据，同难度以原始题目编号决定先后；HSK 等级仅保留作统计。完整定义见 [难度评定](difficulty.md)。
- 同答案关卡编号差至少为 31，即中间至少隔 30 道题。为了间隔，允许局部难度回落；这属于编排策略，不属于良好题目的标准。
- 使用简洁的单页布局，适配桌面及手机；未开放的入口不可点击。
- 许可署名随公开文件保留在 `NOTICE.txt`，游戏页面不展示来源说明。

## 组织与发布

本项目专属页面、题集、工具、测试和文档集中在 `word-kanji/` 内。`public/` 是唯一可部署资源目录，映射至网址 `/puzzle/word-kanji/`。预览服务位于 `word-kanji/scripts/serve.py`，对应测试也在项目的 `tests/` 内；目前没有实际复用需求，不在根目录提前提取工具。私有题库在仓库外。
