# 全量枚举的规模与耗时估计

测量日期：2026-09-09。使用当前固定的 HSK 2025 与 CC-CEDICT 快照，在本机 Windows、Python 3.14.6、单 Python 进程下测量。原始结果见 [space-estimate.json](space-estimate.json)，复现脚本为 [estimate_space.py](../scripts/estimate_space.py)。

## 统计口径

这里的“所有题目”是测量时生成器实现的固定布局：一字十字型（四条边），或二字横向相连型（七条边）。不包括任意新布局。下表沿用原测量口径，上、下、左、右位置不同分别统计为题面记录；它不等同于后来固定的[一字标准型同题定义](wadou-kaichin-rules.md#24-一字标准型的相同题目定义)下的不同题目数。

先枚举 HSK 范围内的答案词，再从 HSK 二字词中选择所有可能线索。统计时已经要求给定字和答案字整体互异，且所有局部词及完整答案都在所选范围；数量**尚未经过扩展词库单解性筛选**。

准确说，候选数量是“题面与预期答案”的组合数。某个多解题面可能以不同预期答案重复进入候选池；单解性筛选会将其排除。它不是最终合格题目数量。

## 精确候选数量

| 生成词汇范围 | 题型 | 至少能配出互异线索的答案词数 | 候选组合数 |
| --- | --- | --- | --- |
| HSK 1–6 | 一字标准型 | 309 | 1,982,836 |
| HSK 1–6 | 二字标准型 | 1,589 | 1,205,095,636 |
| 全部 HSK（含 7–9） | 一字标准型 | 590 | 16,622,336 |
| 全部 HSK（含 7–9） | 二字标准型 | 4,382 | 45,459,833,564 |

这是直接组合计数的结果，不是抽样外推。对每个答案建立四个或六个线索位置的候选字集合，用集合划分上的容斥公式精确计算各位置取字互异的组合数；脚本用小字集的笛卡尔积穷举交叉验证计数算法。

重复摆放会大幅增加数量。例如一字型中，“上方与左方线索互换”和“下方与右方线索互换”不改变词约束。现在一字标准型已正式把这四种排列定义为同题，因此表中一字型候选数应除以 4 才是该口径的候选等价类数；交换入字与出字不作合并。当前二字布局也存在两组类似的线索位置对称性，但本文原始数量保留位置排列分别计数的口径，不以一字规范键替代完整多字题的身份定义。

## 时间估计

每种情况按候选组合数对答案加权抽取 128 个满足互异性的候选，测量当前求解器；再用索引原型检查相同样本，确认结果完全一致。索引原型通过前字／后字集合交集定位候选，不再每题扫描整个扩展词库。另对八个加权抽取的答案各实际枚举至多 2,000 个候选，测量包含位置枚举、重复字过滤、题面构造及索引求解的耗时。

| 范围与题型 | 直接复用当前求解器，线性外推 | 索引原型：枚举与校验外推 | 建议预留的计算时间 |
| --- | --- | --- | --- |
| HSK 1–6，一字 | 约 5.5 小时 | 约 6.5 秒 | 10–30 秒 |
| HSK 1–6，二字 | 约 3.0 年 | 约 1.8 小时 | 2–5 小时 |
| 全部 HSK，一字 | 约 44.7 小时 | 约 52 秒 | 1–3 分钟 |
| 全部 HSK，二字 | 约 112 年 | 约 63 小时 | 3–6 天 |

右侧范围是考虑抽样和运行波动给出的工程预算，不是统计置信区间。以上均为本机单进程计算估计，**不包括完整等级记录的序列化、磁盘写入和 HTML 渲染**。没有实际运行数十亿题的全量任务；长期运行的温度、负载、内存及数据分布差异也会影响耗时。

当前 `generator.py` 是随机抽样生成器，每个答案最多输出一题，不是全量枚举器。不能把 `--one` 或 `--two` 调大就实现穷举。索引方法已在估算脚本中实现并验证，但尚未替换正式生成器；要达到右侧速度并完整输出，需要专门实现流式枚举、索引校验、去重和分批存储。

128 个样本的单解通过率分别约为 96.9%、93.0%、98.4%、93.8%。样本有限，这些比例只说明单解筛选未表现出数量级缩减，不能视为最终合格数量的精确计算。

## 输出规模和更实用的目标

即使采用每题约 200 字节的紧凑存储（仅为容量假设，非当前 JSON 格式实测），保存全部二字候选仍分别需要约 **241 GB**（HSK 1–6）和 **9.1 TB**（全部 HSK），单解过滤后预计仍是相近量级。当前带词条证据和缩进的 JSON 会大得多，不适合按此格式存储全量结果。

如果“所有”是指**每个可用答案选一题**，规模则只有上表几百到几千个答案，而且还会经过唯一性筛选。这与所有线索组合的目标不同。实际题库可先按答案覆盖，再限制每个答案保留若干种线索组合，避免产生大量仅替换或对调线索的近似题目。

复现本次估算：

```powershell
python -X utf8 word-kanji/scripts/estimate_space.py --samples 128
```
