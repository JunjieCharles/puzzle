# 词库来源与处理约定

核对日期：2026-09-09。当前生成器选用 HSK 3.0 的 2025 大纲版本；HSK 全等级均属于本项目的常见词汇范围。默认生成上限为 6，可通过 `--max-level 7-9` 使用所有等级。

## HSK 数据

官方依据：[中文考试服务网大纲页面](https://www.chinesetest.cn/syllabus)链接的[《HSK 考试大纲》](https://hsk.cn-bj.ufileos.com/3.0/%E6%96%B0%E7%89%88HSK%E8%80%83%E8%AF%95%E5%A4%A7%E7%BA%B21219.pdf)，封面标注“2025-11 发布、2026-07 实施”。此处确定的是所用词汇大纲版本，不对各地实际考试切换日期作额外推断。

GitHub 来源：[krmanik/HSK-3.0](https://github.com/krmanik/HSK-3.0)，固定提交 `182692ce5a11bc30bdc771835d2f0f27491c25de`。使用 `New HSK (2025)/HSK Words/temp/HSK_Level_*_words.txt` 的七份制表符数据，因为它们保留了词汇编号、跨等级信息、拼音及词性。目录名虽为 `temp`，本项目固定了提交和文件哈希以保证可复现，不运行上游代码。

导入结果覆盖官方词汇编号 `1…11000`，共读到 11,105 行（包括跨等级重复记录等），规范化后得到 10,902 个字面词条。编号连续性检查只能检查完整覆盖，不能排除上游 OCR 的个别误字；原始字段保留在产物中供审查。

这些数字不是官方各级新增词汇配额：同形词去重、可选字展开都会改变本地计数。

处理规则：

1. 删除词条末尾的义项编号，例如 `本1` → `本`；保留原始词条。
2. 明确用括号标记的可选汉字展开为两种书写形式，例如 `没（有）` → `没`、`没有`；不任意删除未带括号的“儿”。
3. 相同字面词条合并，标注所有来源等级中最早的一档。`7-9` 始终保留为一组。
4. 不做简繁转换，不凭空补词；纯汉字以外的条目会记录为跳过。本快照跳过条目数为 0。
5. 不按字频替代词频；“常见”在当前实现中指 HSK 收录。没有进一步主张它必然适合任意母语者年龄段。
6. 单字答案需作为 HSK 词汇条目出现，而不只是出现在 HSK 汉字表中。

## 扩展唯一性词库

使用 [CC-CEDICT](https://www.mdbg.net/chinese/dictionary?page=cc-cedict) 的简体词字段。下载来自 [Punpuf/hsk-syllabus-vocabulary-parser](https://github.com/Punpuf/hsk-syllabus-vocabulary-parser) 的固定镜像提交 `2adf7c9885a17077966922b89de7ce655d7d82a0` 中 `cedict_ts.u8`，词典文件头记录日期为 `2026-02-10T07:50:08Z`。

从该快照提取所有长度为 1 或 2 的纯汉字简体词条，按字面去重，得到 **71,361** 项。保守保留其中的专名、古语、罕见词、异体形式和单字释义条目，不按 HSK 等级或汉字互异性筛除备选解；词语的多个拼音或释义不重复计解。

局部二字词审查集合为“全部 HSK 二字词 ∪ CC-CEDICT 二字词”；一字、二字答案审查集合也分别取同样两库的并集。审查字域隐含覆盖这些完整候选词中的所有字，不限于生成上限或已选答案。

这保证常用生成词库被扩展审查词库包含，但不保证 CC-CEDICT 穷尽所有中文词汇。输出中的“唯一”严格指上述固定快照并集内唯一。
