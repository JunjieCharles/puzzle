# 二字标准型：筛选与排序难度

更新日期：2026-09-11。用户明确要求筛选标准不变，重新定义排序难度。

## 计数范围与方向

沿用 HSK 全等级与 CC-CEDICT 固定快照的二字词并集，按字面去重。`首(c)` 为以 c 开头的组词数，`尾(c)` 为以 c 结尾的组词数。不按出题词汇范围、已用词过滤条件或全题互异性再扣减计数。

用 AB 表示待填的两个字，六个外部线索为上 A、上 B、下 A、下 B、左、右。这里的字母和位置名仅为公式占位，不对应真实答案。

## 筛选保持原标准

六个外部线索的方向计数升序排列，按字典序取大：上 A、上 B、左用词首计数，下 A、下 B、右用词尾计数。为每个可行答案选此序列最大的题面，再在保证最多 311 题的条件下按原优先顺序选题。筛选模型仍为 `broad-directional-word-count-lexicographic-six-v1`。

本次选题、题面及公开 ID 均不变。新排序分数不会反过来影响筛选，也不搜索新分数最高的题面。

## 新排序难度

没有填入其他答案字时，两格的难度分别为：

```text
a = min(首(上A), 首(左), 尾(下A))
b = min(首(上B), 尾(下B), 尾(右))
```

先填 A 后填 B 时，A 给 B 新增的线索为“以 A 开头的词”；先填 B 后填 A 时，B 给 A 新增的线索为“以 B 结尾的词”。

```text
先A后B = max(a, min(b, 首(A)))
先B后A = max(b, min(a, 尾(B)))
最终难度 D = min(先A后B, 先B后A)
```

每一步取线索计数最小值；一种顺序取两步中较大值；整题取两种顺序中较小值。D 越大越难，关卡按 D 从小到大排列。模型为 `two-step-best-order-minimax-v1`。

例如人工计数 a=8、b=20、首(A)=10、尾(B)=2 时，两种顺序分别为 10 与 20，最终 D=10。此例仅说明运算，不对应真实词语。

## 同分规则（当前默认）

1. D 相同，按原六项外部线索计数序列升序比较。
2. 仍相同，沿用原六线索规范键及私有答案字序作为确定性顺序。

这保留了原排序在同分题之间的先后关系；不求和、不按 HSK 等级决胜。

## 公开与存档边界

公开记录的 `difficulty` 改为单个整数 D。两种填字顺序、答案字的方向计数及中间步骤只在私有生成时计算，不导出。审计兼容此前六项数组格式用于历史检查。
