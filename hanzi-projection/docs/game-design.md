# 汉字双视图：实验阶段

更新：2026-11-10。

## 用户确认的方向

- 独立 puzzle 子项目：将单个汉字视为灰度图，分别累计每行、每列的黑度（由原二值统计调整），用折线图展示。
- 当前先验证视觉效果，比较常见文字和不同字体。
- 「汉字双视图」为用户提出的暂定名，名称尚待确定；技术描述为「汉字双向投影」。

## 当前默认与已实现行为

- 本地静态字形实验页，展示同一汉字在多种本机字体下的灰度图、行投影、列投影和平均黑度。通用常见字输入用于字形观察，不构成正式题库。
- 用户确认的默认配置：256×256 采样画布；勾选黑体、微软雅黑和思源黑体。允许手动调整画布与字体；缺失字体禁用，若默认字体均不可用则选中第一个可用字体。
- 80% 字号、常规字重仍是实现默认，尚不是用户确认的玩法规则；字号可调整。
- 思源黑体使用本机安装的 Source Han Sans CN 常规体，不随网页分发字体文件。
- 灰度规则：在不透明白底上绘制黑字，保留 Canvas 抗锯齿灰色；每像素贡献 `1 - 灰度 / 255`，黑为 1、白为 0。按原始编码灰度线性归一化，不作伽马校正。统计用浮点数，不阈值化、不取整、不另加曲线平滑；仅峰值显示保留两位小数。阈值控件已移除。
- 同字号排版，可见边界居中，不按每个字体的边界分别缩放；因此字体自身字面大小差异会保留。
- 用户调整：逐行曲线放在字形左侧，行位置从上到下，与字形画布等高；逐列曲线放在字形下方，列位置从左到右，与字形画布等宽。采样点与对应像素中心对齐，不在绘图区内部预留标题或刻度空间。
- 当前默认：行黑度累计从靠近字形的右侧零线向左增加；列黑度累计从靠近字形的上侧零线向下增加。累计范围统一为 0 至画布边长，禁止每张图独立放大。
- 用 FontFace local() 检测字体；不存在时禁用，不用其他字体冒充。未嵌入、复制或下载字体文件。系统、浏览器及字体版本会影响结果，不用于跨设备确定性出题。
- 可临时隐藏字形和字名观察曲线；输入框仍显示当前输入，因此这只是观察开关，不是保密或正式猜谜模式。
- 默认输入是通用观察字列表；灰度图与投影均运行时计算，仅在内存和当前 DOM 中存在。没有题目 ID、预存投影、答案表、持久化、日志或导出；不得将实验数据作为带解题库提交。
- 最多对比 12 个不同汉字；非汉字过滤，未选字体或输入为空时显示提示。

## 暂未开放

正式题库、判题、随机题目、进度保存、字重对比、字体文件导入、在线字体和部署均未开放。新模式须单独设计答案保护，不直接沿用另一子项目的无尽模式例外。

## 独立效果图的已确认要求

- 用户另行要求生成静态效果图：多个正方形横向排列，逐行曲线放在左侧，逐列曲线放在上方；题图不显示文字、刻度、辅助线或说明。答案对照图在同一位置放回生成投影时的字形，保持对齐。
- 后续效果图将零值基线贴合方框边缘；另试验曲线突出距离与字形采用同一比例尺，即突出距离等于该行／列笔画覆盖的累计长度，灰色边缘按比例折算。
- 这些效果图已在仓库外生成，尚未将上方布局、零间距或等比例幅度应用到实验网页；它们不是网页当前默认。含文字的答案对照图不得提交或作为公开静态资源。
- 面向玩家的说明只解释累计规则，不逐字解析；使用“纯黑计 1、纯白计 0、灰色按深浅计分”的表述，避免单独使用含义不明的“黑度”。

## 观察方法与局限

先固定采样尺寸比较字体，再固定字体比较文字结构；最后改变分辨率观察细笔画和曲线变化。灰度累计可减少二值化跳变，但不保证消除字形本身、字体 hinting 或栅格采样造成的毛刺。横笔容易形成行峰，竖笔容易形成列峰；衬线、笔画粗细、字面大小都会改变曲线。两向投影一般不足以唯一恢复灰度图，正式玩法须另行验证候选汉字间的可区分性。
