# 任意图形相似度与六字体离线多解试验

## 用户要求与试验范围（2026-11-11）

用户要求将此前矩形结构规则扩展到所有涂色图形，使用位置50px、IoU90%阈值，查看哪些当前题目受影响；随后明确补充：仍须要求连通块数相同。沿用已确认的多字体范围：两边使用同一种字体，六字体分别检查，任一字体下完整替代词命中即多解。

历史试验分析v23 Noto的212道已选题及90,299个比较词；当时不更新正式生成器、游戏资源、线上题库或存档，也不补题。用户随后确认正式采用95%规则，见文末“正式采用”。

## 计算口径

- 使用[上一轮六字体试验](rectangle-similarity.md)的原始掩码缓存；校验六个本机字体文件哈希、字面索引、浏览器版本及渲染规格。字体与400px字号、480×480画布不变。
- 新指标忽略面积小于25px的四连通区域，保留其他区域的实际形状，包括孔洞、曲边和内部间隙；不以矩形包围盒替代区域。
- 将整个有效图形的共同包围盒横纵独立映射到单位正方形，只用于结构比较。没有额外平移、旋转、逐块拉伸或模糊处理。
- 原始位置另行检查：两图有效区域共同包围盒中心的曼哈顿距离 **≤50px**，包括半像素中心。位置在归一化之前测量。
- 结构阈值沿用上一轮严格比较惯例，归一化图形 **IoU >90%**；数值计算使用1e-12容差抑制浮点误差，恰好90%不命中。
- 新图形规则要求两字有效连通块数相同，按四连通、单块面积≥25px计数。不额外进行块间排列匹配，其他结构差异交由实际图形IoU计分。
- 将每个二值像素视为小矩形，精确积分两组归一化像素分区的交集与并集。16×16网格仅用于保守上界剪枝，最终分数不来自低分辨率缩略图。
- 新图形匹配与原像素匹配取并集，但都必须满足有效连通块数相同。原像素分数仍要求最大IoU >95%、对应最小曼哈顿平移 <10px，并继续使用不去噪的原始掩码。
- 空白匹配仍依据原始面积：真实空白只匹配真实空白。仅含小噪点的非空字不会因新指标去噪而变成空白替代字。
- 整词必须在某一种字体内所有对应字位均匹配，再对六字体的整词结果取并集；不混搭字位字体、不作相似关系传递闭包。缺字无回退，在该字体中不可验证的词单列排除。

详细题目、替代词、命中字形及字体、分数、位置距离保存在仓库外 `../puzzle-private/hanzi-paint-bucket/all-shape-same-count-position50-iou90-v23/`。`report.html` 为本地报告，标注相对于上一轮矩形95%／40px／六字体20题的新增情况；HSK替代词优先展示。仓库文档与控制台仅保存汇总，不发布题目答案映射。最初未限制块数的试算已被用户补充要求取代，不作为本轮结果。

合成测试覆盖非矩形拉伸不变性、孔洞保留、不同像素网格的独立精确计算对照、归一化面积守恒、噪点与空白边界、剪枝与穷举一致性、位置与IoU阈值边界。

## 95%阈值复试（2026-11-11）

用户认为90%偏宽松，要求将新图形IoU提高到95%再试。其余条件不变：有效连通块数相同、原始包围盒中心曼哈顿距离≤50px、六字体分别检查完整替代词。仍采用严格大于阈值，与原像素规则取并集，且原像素匹配也须满足同有效块数。

复现命令：`python -X utf8 hanzi-paint-bucket/scripts/analyze_shape_similarity.py --iou-threshold 0.95`。默认输出至仓库外 `../puzzle-private/hanzi-paint-bucket/all-shape-same-count-position50-iou95-v23/`，保留90%报告；新报告列出仍受影响的题目、替代词、字体与分数，以及相较90%不再命中的题目。默认不带参数仍复现90%试验，不代表正式生成器已采用任一阈值。

复试结果：六字体合并后 **52题**受影响，全为二字题，其中 **17题**存在HSK替代词。相较90%的71题，19题不再命中，没有新增受影响题。仅删除、不补题时剩160题。

各字体分别命中：Noto 42题、MiSans 45题、HarmonyOS 42题、SimHei 10题、Microsoft YaHei 35题、DengXian 13题。六字体合并相较Noto单字体额外命中10题。与相同95%／50px阈值下的矩形规则25题相比，任意图形规则多命中27题。报告与汇总保持离线，未更改线上版本。
