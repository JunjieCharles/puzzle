# HSK 无重复用字题库

本页为历史二字题库记录。当前默认已切换到[HSK二字＋三字＋四字合并题库](hsk-combined-bank.md)，以该文档的资格、去重范围及混合排序规则为准。

2026-11-10。当前出题范围仅为 HSK 全等级二字词；三字及以上暂不出题。长度过滤在全局用字去重前执行，释放的字可以用于其他二字词。唯一性验证仍使用当前扩展词库（`broad` 加 HSK 三、四字词），只匹配同长度候选，不局限于 HSK 或最终入选题目。

## 当前规则

1. 统一使用 HarmonyOS Sans SC Thin，480×480 画布、400px 字号，保留涂色原位置。
2. 候选词每个字至少有一个独立涂色区域面积≥25像素（480×480分析画布），不能用多个微小区域面积相加达标。该门槛只影响选题，不改变原始掩码、不减少多解验证候选。
   矩形排除：先忽略不足25像素的四连通区域，再判断剩余区域是否为单一四连通块、bounding box 填充率≥99.5%，且无封闭孔洞、缺失像素仅在外沿字号0.5%厚度带内（400px字号对应2px）。面积恰好25像素的区域保留。这样允许边缘栅格化误差，而保留多个有效色块、内部线条、孔洞及深入缺口。该条件只过滤出题词，不减少扩展验证候选；原始题面、面积、难度及多解掩码均不删除噪点。
3. 整词唯一性：每个对应位置先求所有整数像素平移中的全局最大 IoU，再取达到最大值的最小曼哈顿距离；最大 IoU **>95%** 且该距离 **<10px** 时视为近似（均为严格不等式）。另一个同长度扩展词若每个位置均近似，则视为多解并排除。忽略笔画和颜色；不裁切、旋转、缩放，各字独立平移。题面仍保留原位置。详见 [平移判定](shift-similarity.md)。
4. 有近似字形的字允许使用，只有能构成另一个完整候选词时才排除该词。扩展词、词内重复字的词、未入选或因全局用字冲突淘汰的词，均参与替代答案检查。
5. 入选词内部不允许重复字，整套题库每个字也只出现一次。
   编辑性禁用只应用用户指定及授权同类扩展后的28词清单；不按词性自动排除、不自行扩展抽象词范围。该清单只影响出题，禁用词仍属于替代答案候选。
6. 单字覆盖率为“图案暗示的笔画面积／该字完整笔画面积”。词语评分改为各字覆盖率的算术平均：二字词为 `(r₁ + r₂)/2`，越高越简单。各字等权，不按完整笔画面积加权；某字覆盖率为零时，另一字仍能贡献分数。只使用图像指标，不引入词频、词库或 HSK 等级修正。分母是实际墨迹，不是涂色、画布或包围盒面积。
7. 当前“保留最难”实现为按算术平均覆盖率从低到高贪心挑选，已有字被占用则跳过；同分按 Unicode 字面顺序确定。最终从高到低展示（简单→困难）。排序使用精确有理数，显示时才四舍五入。这是难题优先的确定性方案，不是最大题数优化，也不宣称每个入选词对每一个字单独都是绝对最难。

## 实现与文件

唯一性分析复用私有面积数据库中的原位置掩码。将1,337个HSK二字候选字与全部可涂色扩展字比较，以面积比及膨胀后分块交集上界保守剪枝，再计算完整互相关，得到698对符合平移判定的近似字形；通过词长和位置倒排索引检查整词。私有相似对表保留交集、并集、最小曼哈顿距离及一个达到最小距离的最优位移，便于核验。

笔画分析使用相同浏览器及前端渲染函数，逐字验证涂色掩码与原记录一致，提取原始墨迹。默认算法 `medial-axis-facing-paint-v1`：确定性中轴线（rng=0）同时给出局部笔画半径；到涂色区域的距离≤半径+1栅格像素时，将该中轴段对应的墨迹面积视为被暗示。墨迹像素按最近中轴段归属。因此计入的是笔画的一段完整厚度，不只是单像素边缘，也不把整个连通笔画都算作已提示。此方法是几何估计，不是语义笔画识别；交叉点和极近笔画的归属仍是近似，可通过预览页青色叠加检查。

```powershell
python -X utf8 hanzi-paint-bucket/scripts/analyze_strokes.py
python -X utf8 hanzi-paint-bucket/scripts/build_hsk_bank.py
```

笔画指标默认保存在仓库外 `../puzzle-private/hanzi-paint-bucket/stroke-analysis/metrics.sqlite`；题库默认输出至 `../puzzle-private/hanzi-paint-bucket/hsk-bank-demonstratives-questions-v2/`。已有结果不覆盖；首次生成笔画记录后可直接复用。`--output` 指定新私有目录；`--lexicon`、`--extended-lexicon`、`--analysis`、`--stroke-analysis` 指定输入，核对词库、字体、渲染和浏览器版本。`--iou-threshold 0.95 --max-manhattan 10` 表示每个位置 最大IoU>95%且最小曼哈顿位移<10px。`--policy` 默认读取仓库外 `../puzzle-private/hanzi-paint-bucket/vocabulary-policy.json`，只应用其明确列出的词，不作词性推断；词表、原因和策略版本另存于私有题库中供复核。

- `bank.sqlite`：含独立随机 ID、简单至困难序号、私有词答案、等级、涂色面积、完整墨迹面积、暗示墨迹面积、笔画暗示率；附带全部入选字的原位置压缩涂色、墨迹及暗示笔画掩码。题库自身可读取，不依赖分析库联表恢复。另存查询所需相似字对和被排除的多解词供私有复核。
- `summary.json`：仅汇总与版本指纹。仓库内副本见 [hsk-bank.summary.json](hsk-bank.summary.json)。

题库可通过 `scripts/preview_bank.py` 独立本地服务预览题目与答案，默认加载本次形状过滤后的版本，尚未导出公开题面或判题摘要。含答案及映射的 SQLite 只能保留在仓库外，不能作为静态资源发布。通用预览模板不含题目数据，API 仅按页在内存中返回内容并禁止缓存。历史 `hsk-bank/`、`hsk-bank-unique-iou95/`、`hsk-bank-extended-unique-iou95/` 保留作旧版本，不再作为当前题库。
