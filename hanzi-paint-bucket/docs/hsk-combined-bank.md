# HSK 二字、三字与四字合并题库

2026-11-10 用户确认：合并HSK词题库，当前出二字、三字、四字；至少两个字非空且非单矩形，三字词额外要求所有字位非空。同一个字在二字和三字合并范围内最多出现一次，四字范围另计一次；三种长度统一按难度混合排序。

## 当前有效规则

- 候选是HSK全等级二、三、四字词，不将大成语库作为出题来源。大成语库仍用于四字题的单解检查，独立成语题库不并入。
- 每词至少两个字的涂色非空，且不属于单实心矩形。二字词两个字均须达标；三字词全部非空，第三个字允许是单矩形；四字词的其余位置可为空白或单矩形。禁止空白的三字规则仅限制选题，不从多解检查全集中删词。
- 延续最小区域门槛：任何非空字至少有一个独立涂色区域面积≥25像素；完全空白字允许。只有微小区域的字不自动归为空白。
- 单矩形沿用既有识别：分类时忽略不足25像素的区域，剩余为一个四连通块、包围盒填充率≥99.5%、无孔洞，缺失像素仅在外沿2px带。矩形只不计入“至少两字”的资格数量，正常显示、正常计分并按真实图案判多解。原始图案不删噪点。
- 2026-11-10扩展形状分类：包含“开”部件且仅一个有效涂色区域的字，也计入单矩形类，不要求满足上述99.5%几何门槛；二、三、四字均按此分类计算至少两字的资格，其他位置依旧允许单矩形。包含“月”部件且仅两个有效区域的字，也计入日型类；有其他有效区域的不纳入。日型类仍只用于二字词的双日型组合过滤，不全局禁字。部件递归展开使用固定CJKVI IDS快照（同下方结构规则来源），优先无地区标签或含G标签的描述，无此描述时取首个描述；每块≥25像素才有效。当前思源Light HSK候选中有74个月类字、10个开类字，按结构与有效区域数重新分类。新增分类不修改原始图像、难度及相似度。此为当前词库快照实现，扩库或更换字体需重新核对有效色块来源。
- 单解：验证完整扩展词库及成语库中的同长度词，不因出题过滤而删减竞争词。2026-11-11用户确认正式采用六字体任意图形规则：两字有效连通块数相同（四连通、单块≥25px），且整组实际图形包围盒归一化IoU>95%、原位置包围盒中心曼哈顿距离≤50px；与原像素规则（全局最大IoU>95%、对应最小曼哈顿平移<10px）取并集，原像素匹配也要求同有效块数。六字体分别检查完整词，任一字体中所有位置均匹配即排除候选，不混搭不同字体的字位，不做传递闭包。空白按原始面积判定，只匹配原始空白；只有噪点的非空字不当作空白。多解词仍保留在完整比较词库。详细定义见[图形相似度](shape-similarity.md)。
- 难度：每字原始涂色像素面积，再对该词所有字求算术平均，空白计0、矩形按真实面积计入。三种长度均如此；分数越高越简单，不加字数权重。
- 词内不重复字。二字词与三字词共用一个用字集合，四字词使用另一个集合，所有字位均计入（包括空白字、矩形字）。二字与三字相互冲突时同样按精确平均涂色面积从低到高贪心保留最难词，同分按Unicode词面排序。同一个字可在二／三字组和四字组各出现一次，不能同时出现在二字和三字题中。最后统一按精确平均分从高到低混合展示，不按字数分组。
- 应用129词与4字的私有禁用清单，另有1条按字位禁词规则：第二个字为“着”的词不得出题，适用于二、三、四字词，不禁用该字在其他位置的词。2026-11-11累计新增43个精确禁词，保留既有字位规则。词条精确匹配，全局禁字排除所有含该字的候选词；所有禁用项仍参与替代答案检查。
- 四字题不得前两格全空，也不得后两格全空；其余满足资格的空格分布仍允许。空白以原始涂色面积为0判断，不将噪点自动当空白。
- 排除两格均呈“日”形的二字词，按词过滤，不禁用其中的单字；此后同类组合过滤也采用词级规则。当前默认图像判定：忽略小于25像素区域，恰好剩两个上下排列的实心矩形块（分别沿用99.5%填充率及边缘带判定），左右对应边各偏差不超过字号1%（4px），中间空隙大于0且不超过字号8%（32px）。这些几何容差是当前实现默认，非用户指定数值；不要求两块等高，不移动或修改题面。此规则不作用于三、四字词。所有词级规则仅过滤候选，完整比较词库不受影响。
- 二字限定结构规则：右侧为“夬”部件且恰好一个有效连通块的字，不用于二字题，三、四字不受此限制。结构名单保存在私有策略；递归结构依据固定[CJKVI IDS快照](https://github.com/cjkvi/cjkvi-ids/blob/86b4d16159f0079437870408f0ca186e529015db/ids.txt)，不修改图像。当前符合6字。
- 全长度井部件规则：含“井”部件且恰好一个有效涂色连通块的字不用于二、三、四字题；按原始区域面积≥25像素计数。当前5字为井、耕、讲、进、阱。
- 应用[六字体连通块一致性过滤](font-components.md)：忽略不足25像素的区域后，同字在六字体中的块数必须一致；缺字另列。一致性规则只过滤候选；显示、面积使用思源Light字形，多解相似度使用六字体。
- 用户新增整词禁用规则：二、三、四字题若所有非空字位均属于规整矩形网格（两个、三个或四个有涂色字位），则排除整题，不全局禁用其中的字；单行、单列也算，两边不必具有相同行列数。当前默认实现：忽略小于25像素的区域，矩阵分类中的每块采用≥99%矩形填充率、无孔洞及仅边缘2px容差（2026-11-11根据用户补充放宽，覆盖轻微边缘倾斜；单矩形资格和日形分类仍用99.5%）；同行上下边、同列左右边误差≤字号1%（4px），网格必须完整、不缺格，各行间距及各列间距分别相差≤4px，且每条间隙不超过字号8%（32px），要求色块紧凑相邻；不要求各格等宽等高。用户明确“器”不属于此类：其四角色块之间有宽阔留白，必须排除在矩阵分类之外，不因这条规则禁用含它的题目。几何数值是实现默认；用户已确认扩展至三、四字词。非空字位按原始涂色面积>0判断，不能把微小色块当成空白。现有三字词仍要求全部字位非空；三字全矩阵、四字全矩阵，以及四字词三个矩阵字位加一个空白，均排除。若另有非矩阵的非空字位，则不因这条规则排除。原始题面与完整单解比较词库不修改。
- 中、央、追、健、身、者保留用户明确的矩阵分类补充，不因换字体而取消；不全局禁用这些字，不改变其他字的几何容差。原始掩码与单解比较不变。
- 当前思源黑体 CN Light（Adobe v2.005）静态文件字重300；480×480画布、400px字号。此前HarmonyOS测量作为历史保留，不混用。界面使用Light/Medium的OFL子集字体，仅从界面源码取字；题目答案笔画SVG压缩加密，不发布明文字形映射。
- 2026-11-11本次追加全局禁字“受”与5个精确禁词。词条仅按用户给定字序精确匹配，全局禁字作用于所有字位和长度；禁用词仍参与单解比较。具体禁词及新旧词面只存仓库外，本地预览和游戏同步更新，本轮归档时只更新本地，本次统一发布GitHub Pages。

- 2026-11-11再新增1个精确禁词，并按用户确认将健、身归入矩阵类；全矩阵整词过滤扩展到三个、四个涂色字位。只改变候选选题，不全局禁用这些字，不改变原始题面与完整比较词库。

- 2026-11-11用户确认新增按矩形连通块数量过滤：二、三、四字题的每个字若都只有0、1或2个矩形色块，则排除整题，排列不限，不按矩阵组数计数。0指原始涂色面积为0；当前默认沿用有效区域≥25像素、每块填充率≥99%、无孔洞且缺失仅限外沿2px的矩形判定。少于25像素的附带噪点不计块数，但只有噪点的非空字不当作空白。只要有一个字含非矩形有效块或至少3个有效块，就不因本条排除；原有全矩阵等过滤继续独立生效。仅指定为矩阵的字不改变本条几何计数；明确指定为单个矩形的书按1个矩形计入。只改变候选，完整单解比较词库和原始图像不变。

## 生成、存储和预览

假设禁用的试算不直接写入正式策略，也不切换正式预览。生成器支持`--policy`读取仓库外独立策略，搭配`--output`写入独立私有目录；正式禁词仍以默认私有策略为准。试算仍从全部候选重做单解与最难优先去重，不仅查找单个词的直接替代。

```powershell
python -X utf8 hanzi-paint-bucket/scripts/build_idiom_bank.py --hsk-combined --measurement-bank ../puzzle-private/hanzi-paint-bucket/sourcehan-light-font-analysis/measurement-bank.sqlite
python -X utf8 hanzi-paint-bucket/scripts/preview_bank.py
```

沿用空白字支持及私有字形、笔画缓存，核对字体和渲染指纹；使用原始思源黑体 CN Light、480×480画布、400px字号。缓存缺少的指标重新计算。

默认私有目录 `../puzzle-private/hanzi-paint-bucket/hsk-combined-editorial-v27-sourcehan-light-bank/`；词面、掩码、比较词库、题库和相似对仅存于仓库外，拒绝覆盖已有目录，重建通过 `--output` 指定新的仓库外目录。生成时读取并校验六字体计数分析，默认 `sourcehan-light-font-analysis/components.sqlite`，可用 `--font-component-analysis` 指定其他仓库外结果。旧分立库及此前合并版保留为历史版本，不再作为默认预览。

主预览 `http://localhost:8004/puzzle/hanzi-paint-bucket/preview/`。本次将原8006预览也切到同一份合并库，方便旧链接继续使用；启动第二入口可用 `preview_bank.py --port 8006`。8005独立成语库保留。预览按窗口宽高自动选择1～6列、1～4行，每页1～24题，整页不滚动；缩放窗口保留原页首题或跳转目标题号，末页保持相同网格尺寸。下方答案常显、田字格按钮显示文字，资源和API兼容项目子路径、禁止缓存私有内容、禁止下载数据库。不发布任何真实答案映射。
