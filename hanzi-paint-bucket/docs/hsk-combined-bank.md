# HSK 二字、三字与四字合并题库

2026-11-10 用户确认：合并HSK词题库，当前出二字、三字、四字；至少两个字非空且非单矩形，三字词额外要求所有字位非空。同一个字在二字和三字合并范围内最多出现一次，四字范围另计一次；三种长度统一按难度混合排序。

## 当前有效规则

- 候选是HSK全等级二、三、四字词，不将大成语库作为出题来源。大成语库仍用于四字题的单解检查，独立成语题库不并入。
- 每词至少两个字的涂色非空，且不属于单实心矩形。二字词两个字均须达标；三字词全部非空，第三个字允许是单矩形；四字词的其余位置可为空白或单矩形。禁止空白的三字规则仅限制选题，不从多解检查全集中删词。
- 延续最小区域门槛：任何非空字至少有一个独立涂色区域面积≥25像素；完全空白字允许。只有微小区域的字不自动归为空白。
- 单矩形沿用既有识别：分类时忽略不足25像素的区域，剩余为一个四连通块、包围盒填充率≥99.5%、无孔洞，缺失像素仅在外沿2px带。矩形只不计入“至少两字”的资格数量，正常显示、正常计分并按真实图案判多解。原始图案不删噪点。
- 2026-11-10扩展形状分类：包含“开”部件且仅一个有效涂色区域的字，也计入单矩形类，不要求满足上述99.5%几何门槛；二、三、四字均按此分类计算至少两字的资格，其他位置依旧允许单矩形。包含“月”部件且仅两个有效区域的字，也计入日型类；有其他有效区域的不纳入。日型类仍只用于二字词的双日型组合过滤，不全局禁字。部件递归展开使用固定CJKVI IDS快照（同下方结构规则来源），优先无地区标签或含G标签的描述，无此描述时取首个描述；每块≥25像素才有效。当前HSK候选中有72个月类字、10个开类字，已逐字核对图案仅含对应部件色块。新增分类不修改原始图像、难度及相似度。此为当前词库快照实现，扩库或更换字体需重新核对有效色块来源。
- 单解：验证完整扩展词库及成语库中的同长度词，不因出题过滤而删减竞争词。非空字图以全局整数平移最大IoU>95%、达到最大值的最小曼哈顿距离<10px判近似；不裁切、缩放或旋转。空白匹配所有空白，空白不匹配非空。四个或两个位置全部近似才构成替代答案，不做相似关系的传递闭包。
- 难度：每字暗示笔画面积／完整笔画面积，再对该词所有字求算术平均，空白计0、矩形按真实覆盖率计入。三种长度均如此；分数越高越简单，不加字数权重。
- 词内不重复字。二字词与三字词共用一个用字集合，四字词使用另一个集合，所有字位均计入（包括空白字、矩形字）。二字与三字相互冲突时同样按精确平均覆盖率从低到高贪心保留最难词，同分按Unicode词面排序。同一个字可在二／三字组和四字组各出现一次，不能同时出现在二字和三字题中。最后统一按精确平均分从高到低混合展示，不按字数分组。
- 应用86词与1字的私有禁用清单，另有1条按字位禁词规则：第二个字为“着”的词不得出题，适用于二、三、四字词，不禁用该字在其他位置的词。2026-11-10本次再新增1个精确禁词，保留既有字位规则。词条精确匹配，全局禁字排除所有含该字的候选词；所有禁用项仍参与替代答案检查。
- 四字题不得前两格全空，也不得后两格全空；其余满足资格的空格分布仍允许。空白以原始涂色面积为0判断，不将噪点自动当空白。
- 排除两格均呈“日”形的二字词，按词过滤，不禁用其中的单字；此后同类组合过滤也采用词级规则。当前默认图像判定：忽略小于25像素区域，恰好剩两个上下排列的实心矩形块（分别沿用99.5%填充率及边缘带判定），左右对应边各偏差不超过字号1%（4px），中间空隙大于0且不超过字号8%（32px）。这些几何容差是当前实现默认，非用户指定数值；不要求两块等高，不移动或修改题面。此规则不作用于三、四字词。所有词级规则仅过滤候选，完整比较词库不受影响。
- 2026-11-10新增二字限定规则：右侧为“夬”结构，且忽略不足25像素噪点后恰好一个涂色连通块的字，不用于二字题；三、四字不应用此禁用。此规则与99.5%的单矩形识别独立，不修改图像或比较词库。当前HSK候选中符合条件6字，具体名单存于私有策略。结构依据[CJKVI IDS](https://github.com/cjkvi/cjkvi-ids/blob/86b4d16159f0079437870408f0ca186e529015db/ids.txt)的左右结构，右部为该部件；固定快照、来源指纹保存在仓库外`structure-source/`。连通块数由当前HarmonyOS原始区域面积重新计算。二、三字共用去重，因此二字资格改变也可能间接改变三字入选结果。
- 应用[六字体连通块一致性过滤](font-components.md)：忽略不足25像素的区域后，任一字体连通块数不一致的字不得出题。过滤只影响候选，不删减替代答案词库；显示和难度仍基于HarmonyOS原始图像。

## 生成、存储和预览

假设禁用的试算不直接写入正式策略，也不切换正式预览。生成器支持`--policy`读取仓库外独立策略，搭配`--output`写入独立私有目录；正式禁词仍以默认私有策略为准。试算仍从全部候选重做单解与最难优先去重，不仅查找单个词的直接替代。

```powershell
python -X utf8 hanzi-paint-bucket/scripts/build_idiom_bank.py --hsk-combined
python -X utf8 hanzi-paint-bucket/scripts/preview_bank.py
```

沿用空白字支持及私有字形、笔画缓存，核对字体和渲染指纹；使用原始HarmonyOS Sans SC Thin、480×480画布、400px字号。缓存缺少的指标重新计算。

默认私有目录 `../puzzle-private/hanzi-paint-bucket/hsk-combined-editorial-v12-bank/`；词面、掩码、比较词库、题库和相似对仅存于仓库外，拒绝覆盖已有目录，重建通过 `--output` 指定新的仓库外目录。生成时读取并校验六字体计数分析，默认 `font-component-analysis/components.sqlite`，可用 `--font-component-analysis` 指定其他仓库外结果。旧分立库及此前合并版保留为历史版本，不再作为默认预览。

主预览 `http://localhost:8004/puzzle/hanzi-paint-bucket/preview/`。本次将原8006预览也切到同一份合并库，方便旧链接继续使用；启动第二入口可用 `preview_bank.py --port 8006`。8005独立成语库保留。预览仍每页12题、桌面每排4题、下方答案常显、田字格按钮显示文字，资源和API兼容项目子路径、禁止缓存私有内容、禁止下载数据库。不发布任何真实答案映射。
