# HSK 三字及以上独立题库

本页为历史记录。当前已改为[HSK二字＋三字＋四字合并题库](hsk-combined-bank.md)，三字要求全部字位非空，按字数分别用字去重、混合排序。8006入口本次也已切到合并库；下文的旧生成、预览参数仅用于历史复现。

2026-11-10 用户确认：仍以HSK词库出题，三字及以上另建题库，沿用至少两字有涂色的规则。

## 当前规则

- 来源为现有HSK全等级词表，长度≥3。当前快照含391个三字词、458个四字词，无更长词；不限制为成语。
- 每词至少两个字有涂色。完全无涂色的字允许，保留原田字格位置；任何非空字必须至少含一个≥25像素的独立涂色区域。不能把微小区域自动当成空白。
- 沿用HarmonyOS Sans SC Thin、480×480画布、400px字号、原位置显示。按用户最新澄清，本库不再排除含单实心矩形字的词：矩形仍正常显示，计入非空涂色字数，按真实掩码参与单解检查与笔画覆盖率计算，不与空白合并，也不归零。原HSK二字库和独立成语库的矩形过滤保留。用户授权禁词清单也应用于选题，当前28条均为二字词，不影响本库。
- 单字覆盖率＝暗示笔画面积／该字完整笔画面积；整词取所有字的算术平均，空白字计0，各字等权。越高越简单。
- 唯一性验证使用完整成语库及现有HSK、扩展词库三字及以上词，只匹配同长度词。每个非空字位要求全局整数平移最大IoU>95%，且达到最大值的最小曼哈顿距离<10px；两个空白字图视为相同，空白与非空不匹配。各字独立平移，不旋转、缩放或裁切。
- 不因出题资格、词内重复、禁用或最终落选而删减替代答案词库。单解保证限于当前词库快照、字体及栅格判定范围。
- 先排除词内重复字，再按精确算术平均从低到高贪心保留最难词；同分按Unicode词面排序。库内全局每字只出现一次，三字和四字共用这套去重状态，空白字同样占用。与HSK二字库及独立成语库分别维护，不跨库去重。展示从简单到困难。

## 生成与预览

```powershell
python -X utf8 hanzi-paint-bucket/scripts/build_idiom_bank.py --hsk-multi
python -X utf8 hanzi-paint-bucket/scripts/preview_bank.py --hsk-multi
```

复用支持空白字位的成语生成器和已有字形／笔画分析；成语词库来源及获取方式见[成语题库文档](idiom-bank.md)。可选复用已有成语私有分析缓存，先校验字体、栅格和浏览器指纹。

私有输出默认 `../puzzle-private/hanzi-paint-bucket/hsk-multi-rectangles-bank/`，不允许仓库内输出或覆盖已有目录。旧 `hsk-multi-bank/` 保留作矩形过滤版本。词面、掩码、题库、比较全集与相似对全部在仓库外；仓库仅维护通用代码、模板及无答案统计。

独立预览为 `http://localhost:8006/puzzle/hanzi-paint-bucket/preview/`。沿用每页12题、桌面每排4题、田字格、下方答案常显、格内答案叠加和青色暗示笔画检查。API禁止缓存、禁止读取数据库文件；不作为静态发布产物。
