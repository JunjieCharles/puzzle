# 矩形结构相似度离线试验

## 当前范围（2026-11-11）

用户要求试验基于矩形的相似度，查看当前题库会受到哪些影响。第一轮为不带位置约束的 Noto 单字体分析；后续根据用户反馈增加原始位置约束与六字体检查，见文末。本次只分析 v23 Noto 题库的 212 道已选题及其原有 90,299 个替代词，不修改正式判题、正式多解规则、题库、存档版本或线上资源；不执行过滤后的重新选题与补题。

以下是本次试验默认实现，不代表用户已经确认采用此规则或任何阈值。

## 指标定义

- 使用当前 Noto Sans SC Thin 的 480×480、400px 字号原始涂色掩码及已有字体哈希校验。
- 四连通区域小于 25px 时仅在新指标中忽略。其余区域均须满足矩形填充率至少 99%、无内孔、缺失仅限外侧 2px 边缘。空白不产生矩形签名。此处使用几何检测，不套用人工“规整矩阵”字分类。
- 每个区域用其包围矩形表示，将整组矩形的共同包围盒横纵分别归一化到单位正方形。忽略整体位置、尺度与宽高比，保留内部相对尺寸和间距。不是逐块归一化。
- 两字矩形数量必须相同。按矩形交集最大权匹配建立一一对应，匹配后各矩形之间左右、上下分离关系必须一致；否则本指标返回零。并列最佳匹配按求解器默认结果处理，未枚举全部并列匹配。
- 相似度为归一化矩形并集之间的连续几何 IoU，直接计算矩形交集面积，不进行二次栅格化。原始笔画和非矩形色块不适用该指标。
- 新指标严格大于阈值即加入相似字对，与原有像素规则取并集。沿用原规则的同长度逐位置匹配、空白只匹配空白、不传递闭包，并从原完整替代词库寻找完整替代词。
- 原始宽高比差异暂不作为门槛；该试验用于发现结构歧义，不等同于确定人类感知相似度。没有新增位移限制。

## 结果

| 新指标阈值（严格大于） | 新增受影响题数 | 其中存在 HSK 替代词 | 仅删除、不补题时剩余 |
| --- | ---: | ---: | ---: |
| 80% | 66 | 23 | 146 |
| 85% | 64 | 22 | 148 |
| 90% | 63 | 22 | 149 |
| 95% | 58 | 18 | 154 |
| 98% | 35 | 11 | 177 |

95% 档影响 54 道二字题及 4 道四字题，没有三字题。HSK 标记只表示替代词是否在现有 HSK 数据内，不能把所有扩展词都判作生僻或误报。全部替代词仍参与试验。

原有像素规则对这 212 题的唯一性基线已核验。共有 2,887 个比较字满足矩形签名条件，其中当前题目涉及 216 个。当前 95% 可作为人工审查入口，尚未确认用于自动过滤。

## 第二轮：原始位置与六字体

用户补充要求：不能只比较归一化结构，还应考虑色块位于字形中的原始位置；多解检查应加入不同字体，只要任一字体命中就算多解。用户明确选择“两边使用同一种字体，六种字体分别检查”，不是固定 Noto 题面与其他字体的替代字交叉比较。

本轮实现与当前默认：

- 新矩形规则继续使用归一化 IoU >95%，额外要求两组有效矩形的整体包围盒中心在原始480px画布上的曼哈顿距离不超过门槛。比较30、40、50px三档；40px是根据用户给出的正反例选择的试验默认，并非已确认正式阈值。中心可以落在半像素位置。
- 归一化仅用于结构分数，绝对位置另行测量，不能在归一化后计算位置差。尺寸和宽高比仍可不同。
- 使用此前六字体检查的同一组本机字面：Noto Sans SC Thin、MiSans Thin、HarmonyOS Sans SC Thin、SimHei Regular、Microsoft YaHei Light、DengXian Light。画布、字号、像素门槛与原算法一致；完整字形居中，涂色区域不单独居中。
- 每种字体分别生成所有可覆盖比较字的掩码，分别执行原像素相似规则与带位置约束的矩形规则。新矩形规则与像素规则取并集；原像素规则仍为全局最大IoU >95%、对应最小曼哈顿平移 <10px。
- 当前默认以完整替代词为单位取六字体结果的并集：至少有一种字体使整词所有对应字位均匹配，才算多解。不会把不同字体各自命中的不同字位拼成一个替代词，也不对字对关系做传递闭包。
- 缺字不回退，不视作空白；在该字体中排除无法完整渲染的比较词并单列无法验证的当前题目数量。其他字体仍可验证该词。此前禁用的候选字不因此从替代词库移除。
- 此轮同时给出仅像素规则的六字体结果，用于区分新增字体本身与新矩形规则的影响。

入口：`python -X utf8 hanzi-paint-bucket/scripts/analyze_multifont_similarity.py`。私有掩码缓存、字体指纹、逐字相似关系、题目与替代词报告保存在 `../puzzle-private/hanzi-paint-bucket/multifont-position-v23/`；公开目录和控制台只保留汇总。缓存以字体哈希、字面索引、浏览器版本、渲染规格验证，像素字对缓存另校验查询字与覆盖范围。

### 第二轮结果

| 规则 | Noto 单字体受影响题数 | 六字体并集受影响题数 | 并集中存在 HSK 替代词 |
| --- | ---: | ---: | ---: |
| 仅原像素规则 | 0 | 1 | 0 |
| 像素或矩形，矩形中心距离≤30px | 14 | 16 | 2 |
| 像素或矩形，矩形中心距离≤40px | 17 | 20 | 3 |
| 像素或矩形，矩形中心距离≤50px | 19 | 25 | 5 |

40px档的20题全是二字题；全部包含在第一轮58题中，因此38题因位置约束不再被标记。与Noto单字体同样的40px规则相比，多字体额外发现3题。仅删除、不补题时剩余192题，这不是重新生成后的最终题库数量。

| 字体 | 仅像素规则 | 像素或矩形，中心≤40px |
| --- | ---: | ---: |
| Noto Sans SC | 0 | 17 |
| MiSans | 0 | 17 |
| HarmonyOS Sans SC | 1 | 17 |
| SimHei | 0 | 3 |
| Microsoft YaHei | 0 | 13 |
| DengXian | 0 | 6 |

HarmonyOS与SimHei各缺22个扩展比较字，其余四字体覆盖全部6,795字；当前212题在六字体中均可完整渲染。Noto重绘的6,795个原始掩码逐像素核对与当前题库一致。用户提供的两组负例在六字体中均不匹配，两组正例及此前的横条示例至少在一种字体中匹配。

结论仍为离线试验：40px档符合当前给定正反例，已生成私有逐题、逐字体明细供审查；未修改生产生成器、线上题库或存档版本。
