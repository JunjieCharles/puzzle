# 扩展词库统计（当前）

2026-11-10。字体统一为 **HarmonyOS Sans SC Thin Version 1.0**，排除单字词条；字符只从剩余词条提取。保留原位置，不对涂色整体居中。

## 范围

当前默认使用现有通用扩展词库 `word-kanji/public/endless-lexicon.json` 的 `broad`（HSK + CC-CEDICT，一至二字），并补回先前 HSK 统计中的三、四字词。合并去重后删除 10,982 个单字词条，最终 **61,232 个词条**，其中二字词 60,383 个、三字词 391 个、四字词 458 个，覆盖 **6,134 个不同汉字**。

未对 CC-CEDICT 中的人名、地名、罕见词等做额外筛选；词库覆盖不等同于常见词可玩性。该快照不包含 CC-CEDICT 的全部长词，新增三、四字词来自 HSK。

## 结果

| 类别 | 数量 |
| --- | ---: |
| 有涂色块的字（总面积至少 1 像素） | 3,986 |
| 有字形但无闭合涂色区的字 | 2,099 |
| 字体缺字，未参与渲染判定 | 49 |
| 每个字均有涂色块的词 | 18,586 |
| 其中二字词 | 18,526 |
| 其中三字词 | 37 |
| 其中四字词 | 23 |

有涂色块的字约占字符全集的 65.0%。缺字是独立类别，不能视为“无闭合区域”，也不允许用浏览器替代字体产生结果。

若要求每个字的**总涂色面积至少 25 像素**，则有 **3,966 个字、18,327 个词**合格，其中二字词 18,268 个；这会剔除 20 个仅含微小封闭区的字。门槛提高到 100 或 400 像素时，本次计数不变。面积门槛尚未作为正式选题规则。

## 数据与验证

继续使用与前端相同的 480×480 画布、400px 字号、alpha≥128 笔画阈值、四邻接闭合判定。复现命令：

```powershell
python -X utf8 hanzi-paint-bucket/scripts/analyze_hsk.py --scope extended --skip-similarity --output ../puzzle-private/hanzi-paint-bucket/extended-analysis-new
```

本次仅更新数量和面积，不进行扩展词库全量多解分析；此前 HSK 的 IoU 统计是历史结果，不能套用到这里。

- 仓库外 `../puzzle-private/hanzi-paint-bucket/extended-analysis/analysis.sqlite` 保存 6,085 个有字形字符的面积、各区面积、原位置掩码与合格词，另在 `missing_glyphs` 表保存 49 个缺字。
- 同目录 `character-areas.csv` 保存 6,085 条逐字面积明细；未把缺字错误记成零面积。
- [不含字词映射的汇总与版本指纹](extended-analysis.summary.json)。

对全量记录核对各区面积之和、掩码面积及总面积，核对所有合格词均为二字以上且各字有涂色；与历史 HarmonyOS 数据共有的字逐一核对原位置掩码一致。分析明细不进入仓库或前端。
