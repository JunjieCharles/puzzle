- 默认以 6×6 网格给汉字不同的连通块分配空间；网页可选择 5×5、6×6、7×7、8×8。

## 从例图得到的观察（不是已证实的原作规则）

参考来源为本次会话中用户提供的图片；未将带真实解答的参考图保存进仓库。没有查到可核实的原作者算法说明，因此以下属于图像观察与推断。

1. 外框为正方形，内墙为网格边上的水平、竖直线，房间可以是非矩形，甚至包围其他小区域。
2. 按笔画接触关系划分，比按语义偏旁划分更能解释例图。独立的点、撇、横可能各自占一个房间；接触的多笔画结构可能共用一个大房间。
3. 空白位置可以留下小块；部分例图用灰色显示。灰色是否始终意味着无字形区域，尚不能仅凭图片确定。
4. 某些叠字示意中的笔画会跨越墙线或伸入灰格。因此严格“每个墨迹像素都在自己的房间内”可能不可行，也可能与原作者的字体、摆放或示意方式有关。
5. 简体字与日语字形的连接关系不同，不能直接继承日语版本的部件拆法。必须在实际使用的字体、字重上重新提取。

## 离线生成器的默认实现

以下是本次实验采用的默认，尚未由用户确认为最终规则。

- 使用 SC 简体中文版本 ExtraLight，不使用日文字形，也不对笔画做侵蚀、细化或人为拆分。
- 以 600 像素字号绘制，墨迹阈值为 96/255；按八邻接提取字形连通块，避免斜线被拆成像素碎片。
- 裁到字形墨迹边界，保持宽高比，置于 360×360 画布。搜索占最大边长 88%、92%、96% 三种缩放，以及横纵各 -6、0、6 像素平移，共 27 种摆放。
- 对连通块标签做最近邻缩放以保留来源身份；不因缩放后像素的偶然接触而重新合并标签。这是离散近似，后续需检查阈值、分辨率敏感性。
- 以每块自身墨迹总量归一化，先用逐格最佳归属的墨迹损失下界选择摆放；优先避免种子格没有所属墨迹的情况。摆放阶段不联合求解连通约束。
- 每个连通块分配一个非空、四邻接连通的房间；不同房间不重叠。一格最多属于一个房间，可以不分配给任何房间。
- 未分配格合并显示为灰色空白区域，不作为汉字连通块计数。
- 参考图中的小空白区是保留还是并入相邻房间，当前没有统一结论。本次偏向保留空白。

## 离线生成器的优化模型

令 `a[k,c]` 表示连通块 k 在格 c 中的墨迹量除以该连通块总墨迹量；令二元变量 `x[k,c]` 表示格 c 是否分配给 k。

目标最小化：

```text
Σ_k (1 - Σ_c a[k,c] x[k,c]) + 0.008 × Σ_k,c x[k,c]
```

第一项惩罚每个连通块未被房间覆盖的墨迹比例，独立小点与大部件具有相同总权重，避免大部件轻易吞掉小点。第二项轻微惩罚占用面积，避免无必要地吞并空白。两项可以权衡，所以即使一格只有单个连通块的少量墨迹，也可能保留为空白；不是严格覆盖模型。

约束：每格最多一个归属；每块必须有固定种子格；通过网格邻边上的单源流约束，保证每个已分配格与本块种子格连通。种子格由线性指派算法选择，互不重叠，尽量捕获各块墨迹。

使用 SciPy `milp` 求混合整数线性规划。每字默认限时 10 秒，相对 gap 容差 0.5%；报告保留求解状态与 gap。限时有可行解时可输出，并保留限时状态；没有可行解则报错，不伪装成合格分区。

这能形式化用户猜测的“最优化问题”，但不等于证明恢复了原作算法，也不保证在所有摆放、种子选择和目标权重上全局最优。当前没有墙长、拐角数或房间形状美观度项。

## 结果阅读与已知限制

每个实验字展示纯户型与灰字叠加对照，标注墨迹连通块数、越界墨迹比例和空白格数。报告另记单个连通块的最坏损失、字体 SHA-256、画布大小、阈值、摆放及求解指标。

首轮 12 字实验：连通块数为 3–8，平均越界墨迹约 4.83%，单字总墨迹越界约 0.01%–12.38%；均得到 gap 容差内的优化结果。为避免在文档中建立题面与答案映射，具体字及图仅保存在私有目录。

- 越界比例是离散像素覆盖指标，不等于字形识别率，也不等于玩法质量。显示到小数一位的 0.0% 不一定严格为零。
- 房间连通性已约束；汉字猜测的唯一性尚未验证。不同汉字可能生成同一户型，不能据此直接称为唯一解题库。
- 有些复杂字实际连通块很少；笔画多并不必然适合作题。
- 在固定字体和 6×6 粗网格下，不同块可能占据同一格，严格分离所有墨迹会无解。当前允许损失，不在图中偷偷改造笔画连接关系。
- 还需要比较更多摆放、部件级形变是否允许、空白显示方式和题面辨识度，才能确定正式玩法。
- 未开放：游戏流程、答题判定、难度排序、公开题库、线上部署。已增加下面的本地字体对比网页。

## 2026-11-10：默认铺满与上部近似对称结构诊断

用户确认默认“相同可见边长 + 100%”，并要求分析一个上下结构样张与参考图的差异，尤其是上部划分不对称。本次仅修改默认排版并开展诊断，不擅自加入强制对称规则。等比缩放意味着最大可见边长铺满，另一方向可以保留字形比例造成的留白，不进行横纵独立拉伸。

诊断方法：对五款已加载字体使用网页同一份像素、阈值、摆放和 36 格墨迹统计，分别计算浏览器启发式和 Python 固定种子的 MILP；另作水平镜像复算，以及人工构造的对称结构候选对照。真实字形与具体分区、候选、截图仅保存在仓库外，不在文档中建立题面解答映射。

结果及解释：

- 五款字体上两种求解方法均得到相同分区，MILP gap 为零。该结论限于相同摆放、种子和目标，不是所有可选规则的全局最优证明。
- 镜像输入后再将输出翻回，分区逐格一致。本样张未发现扫描顺序造成额外方向偏差；不据此断言算法对任意输入都镜像等变。
- 第一款字体的上部成对小部件并非精确镜像；其成对中心对应的对称轴相对画布中心约偏 6 像素，宽度差约 4–6 像素。粗网格会把小幅跨线放大为一整格的归属变化。
- 当前目标按每块自身总墨迹归一化，使小部件和大外框各占一个单位权重。对称候选的总墨迹越界从约 14.4% 降到 11.5%，但逐部件归一化损失从约 0.459 升到 1.725，因此当前评分仍选择不对称方案。候选不排斥当前固定种子，差异不是种子约束单独造成。
- 页面展示的是总墨迹越界比例，算法优化的却是逐部件等权损失加面积惩罚，二者不一致。前者更小并不表示现有目标更优，必须明确区分。
- 原参考图更接近保留外框／留出规则小房间的结构抽象；这是图像观察推测，尚无原作者算法证据。单纯改用精确求解器不能解决目标不匹配。

诊断提出的改进方向曾在下面的结构优先分配中试验，随后按用户要求撤回：混合绝对墨迹与逐块覆盖权重，对近似镜像部件增加软对称代价，增加墙长、拐角与紧凑度代价，同时保留每块非空和连通约束。不能对整个汉字强制镜像，也不能只为一个真实字硬编码特殊分区。


## 2026-11-10：结构优先分配（历史试验，已撤回）

用户授权自行调整算法，使其更符合参考图预期。已替换首版前端评分与局部搜索；离线 Python 生成器仍保留原模型，不能混称为相同算法。默认排版继续为相同可见边长、100%。

实现选择与参数（工程默认，不是原作规则的定论）：

1. 覆盖收益改为 `0.8 × 连通块数 × 整体墨迹覆盖率 + 0.2 × 各块覆盖率之和`。整体墨迹占主导，小部件仍获得部分独立权重。每块房间非空、四邻接连通、互不重叠仍是硬约束。
2. 从当前阈值后的实际像素取得每块的包围盒，以格为单位计算面积目标 `A=max(1,宽×高)`。超过该面积的空间按 `0.12 × max(0,房间格数-A)²/A` 惩罚，防止小笔画成为长条大房间。包围盒较大的外框与跨区部件仍可以拥有宽广或包围式房间。只有格子墨迹统计、没有像素包围盒的调用使用保守格子包围盒估计。
3. 对归一化墨迹分布做轻微横向平滑（0.2/0.6/0.2，边缘保持质量），仅用于寻找近似镜像部件，不改变字形或覆盖统计。候选墨迹量之比至少 0.65，镜像 L1 差小于 0.4；若不同部件的包围盒中心、宽高同时近似镜像，可放宽至 0.55。按最相似优先进行不重复匹配，允许自身近似镜像。不同高度或明显不同形状不强行配对。
4. 对选中配对的房间镜像不一致施加软代价，逐格强度为 `0.07 × (1-差异/0.8)`。并非要求整个字镜像；非匹配部件不受此项约束。
5. 保留每占用格 0.008 的面积代价，增加每条内部房间边界 0.004、每个内部网格顶点处凸／凹角 0.002 的轻微复杂度代价，减少无意义折线。
6. 先做不重复种子指派与连通路径扩张，再搜索单格移动和成对镜像移动。后者可以跳过“单独移动一侧会暂时更差”的障碍。只接受评分严格改善且所有房间保持非空连通的变化，最多 100 轮。结果仍是启发式近似，无全局最优保证。

页面将越界明确说明为覆盖指标而非完整评分，保留字形叠加供观察结构取舍。未增加任何按字特判、部首字典、真实题面分区或可关联答案资源。图形数据仍只在本页内存中计算。

## 2026-11-10：最小总越界（当前有效前端规则）

首要优化目标为（2026-11-10 补充同越界时最小占用格数）：

```text

```

同一字形和阈值下，总墨迹数固定，最小化越界像素数与最小化页面显示的总越界比例等价。每个像素权重相同，不按连通块大小归一化，也不因形状不好看而扣分。

求解与最优性说明：

1. 放松连通性，仍要求每块房间非空。先计算每格最大可覆盖墨迹 `M[c]`。为每块选一个互不重复的代表格，其机会损失是 `M[c]-ink[k,c]`。匈牙利指派最小化总机会损失，其他格分给最大墨迹部件，由此精确求得放松问题的最大覆盖率，形成原问题越界下界。
2. 先检查逐格最大墨迹的原始分配：如果每块非空且连通，直接使用，不能用代表格覆盖它。否则去掉放松解中没有必要的空白代表格，再检查连通性。覆盖数达到放松上界且满足连通时，得到原问题的全局最优解（仅针对当前固定字形、网格和阈值）。
3. 如果不连通，从放松分配中选择各块实际拥有墨迹最多的格子，以及按原始墨迹指派的另一组种子，作为两种起点，连通路径扩张后做单格移动和两格交换，只接受总覆盖像素数增加的改变。种子只用于初始化，不固定为最终必须保留的格子。最多 100 轮，选择覆盖更多的可行方案。

5. 总越界相同时，以所有非空房间占用的格子总数最小为次级目标；不为减少占用牺牲一个墨迹像素。仍不要求对称，不添加其他美观评分。

- 仅用中心线作硬性内外判定仍会在穿过格线时突变。因此每个中心线点按横纵独立均匀扰动 `[-3,3]` 像素计算落入各格的概率，所有点的期望越界之和作为主目标。等价于在固定房间下对小平移扰动求平均；不为每个扰动重新优化分区。
- 对于一条靠近竖直边界的线，落在边界上时两侧各得一半计分；移动 1 像素时每点损失约变化 1/6，而非由 0 立即跳到 1。水平情况相同。固定半径是位置不确定性的平滑尺度，不沿用真实笔画粗细。
- 外框的微扰坐标按边缘钳制，质量不丢失。每点固定 1024 个计分单位，用最大余数法分到各格，保证总量精确守恒、保持整数下界证明。量化会产生小台阶；“已证明最优”只针对该离散、量化模型和当前采样范围，不是连续几何最优。
- 骨架只从未微调的来源字形提取一次，随同一候选平移，不因每次变换重新细化或重新解释连通块。画布仍为 384×384，大小 0%、位移 ±10 像素步长 2、禁止裁切。所有支持的网格尺寸共用同一像素平滑半径。
- 同损失仍最小化占用格数；不加入对称、墙长等评分。新模式可能为了降低贴边微扰下的损失占用边界两侧更多格子，这是所选主目标的结果。
- 页面将新目标标作“平滑损失”，微调前后使用中心线点当量，不冒称墨迹像素。另列实际墨迹越界像素及比例供参考，该数值可能变大，且不是新模式的最优化目标。新增“笔画中心线”观察模式，显示基准骨架以便检查提取质量。

局限：这是栅格骨架，不是字体设计的原始笔画路径，也不做笔顺识别；斜线按骨架像素采样计权而非严格欧氏弧长。端点、交叉处和近邻笔画仍受字体轮廓与阈值影响，不保证完全独立于笔画粗细。固定分区的分数更平滑，不代表离散最优分区绝不会切换。真实题目、骨架与分区映射均只在运行时内存处理，不保存或发布。

验证使用人工点、2×2 块、边缘竖线、斜线、十字与闭环，检查来源标签、连通、保留孔洞、幂等性、横竖跨线响应、各网格质量守恒及位移搜索不劣于基准。

### 2026-11-10 房间八连通实验

用户根据原片怀疑连通块采用八连通，并要求本项目尝试。字形像素原本已经使用八连通提取；本次改变的是分配后的房间格子连通性。配置新增“房间连通”，当前默认八连通（共边或仅共角均算连通），保留四连通（必须共边）对照。原片是否确实采用此规则尚未证实，不把截图推测写为已知规则。前文四连通实验及验证记录为历史行为，当前页面以本条为准。

同一模式用于初始生长、路径、移除检查、交换验证、裁剪空格、连通性割及分支定界，位移搜索也传递此配置。求解器缓存按网格尺寸及连通性区分，避免切换时混用邻接关系。通用函数为兼容原实验调用仍默认四连通，页面显式传入所选值。两种评分目标、五至八阶网格均支持切换，其他默认参数保持不变。

八连通下不同房间可以在同一个格点对角交叉，但不能占同一格；轮廓仍按相邻格的归属画墙，点接触的同一房间可能看起来像独立小区域。不以额外规则禁止这种顶点交叉，保留用户要求的纯八邻接定义。显示最优时仅指所选连通规则下的所选目标，不能用八连通结果宣称四连通最优。骨架提取及来源部件身份不随房间连通选项改变。

验证包括人工对角两格无需桥接、四连通需多占一格、两个部件只在顶点交叉、行尾不回绕、跨尺寸切换与位移搜索配置传递。
